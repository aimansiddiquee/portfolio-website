# 🌐 Developer Portfolio Website — Aimen Shahzad

A clean, responsive, and interactive personal developer portfolio built with **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**. Features an automatic dark/light theme switch, dynamic fetching of public repositories via the **GitHub REST API**, and showcases of key projects and skills.

---

## ✨ Features

- **Responsive Design:** Mobile-first layout using Tailwind CSS flex/grid utility classes.
- **Theme Switcher:** Seamless Dark / Light mode toggle with persistent preference setting.
- **Dynamic Repository Showcase:** Real-time fetching of GitHub projects using the `fetch()` API.
- **Interactive Project Cards:** Categorized project views including Database Systems, Web Applications, and Design Work.
- **Contact Form:** Embedded direct form with active validation.

---

## 🛠️ Tech Stack & Skills Highlighted

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS (via CDN)
- **Database & Backend Tools:** MySQL, Relational Database Design
- **Design & Content:** Figma, Canva, CapCut
- **API Integration:** GitHub REST API v3
